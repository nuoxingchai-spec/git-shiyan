# 设计说明

## 模块划分

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 数据模型 | `include/student.h` | 定义 `Student` 结构体与成绩计算接口 |
| 业务实现 | `src/student.c` | 总分、平均分、等级、格式化输出 |
| 程序入口 | `src/main.c` | 构造样本数据、驱动输出 |

## 分支策略（实验 5 使用）

- `master`：可发布的主线
- `feature/<name>`：特性分支，一次只做一件事
- `bugfix/<name>`：缺陷修复分支
- 合并统一走 `git merge --no-ff`，保留分支拓扑，便于回溯

## 版本标记

- `v0.1`：首个可运行版本（标签）
- `v0.2`：加入排序功能后的版本（标签）
